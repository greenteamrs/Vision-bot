---
name: Seasonal rank progression
description: Permanent-rank tracking while a higher seasonal WOM rank is active.
---

Seasonal ranks can sit above permanent ranks in the dashboard hierarchy but must never count as promotion targets or suppress ordinary permanent-rank progression.

**Why:** The user runs seasonal ranks and explicitly asked to save the WOM rank that preceded the seasonal change so rank-up checks still assess the original rank.

**How to apply:** Mark seasonal ranks temporary before syncing the transition. Save the previously observed non-temporary WOM rank before replacing it, retain it across repeated seasonal syncs, and update it when WOM returns to a permanent rank.

Ranks above Leader have their own Discord roles. Gnome Child and Leader have no separate rank role; both have Visionaries, as do higher ranks.

**Why:** The user stated this Discord role arrangement. Visionaries alone cannot distinguish the two lower permanent ranks.

**How to apply:** A matching permanent Discord rank role can identify a seasonal member's underlying rank. Otherwise use the saved permanent WOM rank. If neither is known, flag the member for original-rank correction instead of inferring rank from thresholds or treating them as Leader or Gnome Child.
